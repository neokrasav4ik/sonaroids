# Changes

The game's version is in `VERSION`; `build.py` puts it into the game (title screen, logs) and into the service worker.
Bump it with every upload.

| version | date | what changed |
|---|---|---|
| 0.33 | 26 Sep 2026 | Fix: "show a code" drew the screen for a moment and then only space. The game's request helper wrote the HTTP status into the same `code` field the server uses for the transfer code, so the code became the number 200 and drawing the screen failed every frame. The status is now kept apart; the screen test goes through the real request path with a faked server (the old test replaced the request itself and missed it). The server is unchanged. |
| 0.32 | 26 Sep 2026 | The game-over screen gives the place of this very game; when the player has a better one, a second line gives the record's place ("this game: #2 all time" / "your best: #1") — the table shows one line per player, their best game, so a 798 thousand game said "#1" and did not show up in it. A transfer code: HIGH SCORES → TRANSFER → "show a code" on one device, "enter a code" on another (Safari, the home-screen app and another phone are separate players to the game; the maintainer had two lines in the table) — the second device takes over the first one's player, and its own games and name join in. **The server must be updated** (`git pull` + restart): new `/v1/link`, `/v1/claim` and the place of the game; with an old server the game shows the old line and the transfer says "no connection". Rules unchanged (`rules-3`). |
| 0.31 | 25 Sep 2026 | The language screen says, in both languages, "For full screen mode, add the site to your home screen" — only in a phone's browser, not when launched from the home screen. Rules unchanged (`rules-3`), the server needs no update. |
