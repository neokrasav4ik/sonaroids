# Sonaroids для Android

Тонкая оболочка (с 0.41): приложение открывает игру с сайта `https://sonaroids.app/play/` во встроенном браузере (WebView) и добавляет то, чего браузер не умеет:

- разрешение на микрофон спрашивается один раз, как у приложения, и дальше отдаётся игре без вопросов;
- громкость: перед каждой подготовкой приложение само поднимает громкость медиа до 60%, если она ниже («тихо» — самая частая причина неудачной подготовки, 20–45% попыток по серверу);
- экран не гаснет, на весь экран, горизонтально в обе стороны (`sensorLandscape`). В 0.42 было «только разъёмом вправо» — на Redmi это не помогло: встроенный браузер всё равно берёт микрофон у фронтальной камеры, а игру у неё так стало не проверить; вернули в 0.43, пока нет своего выбора микрофона; кнопки громкости меняют громкость зонда;
- журналы (кнопка «ЖУРНАЛ»): WebView не умеет ни «Поделиться» файлами, ни скачивать `blob:` — страница передаёт файлы приложению кусками (`fileBegin` / `fileChunk` base64 / `fileEnd`), приложение кладёт их в Загрузки/Sonaroids и открывает «Поделиться» (`shareFiles`);
- для игры есть `window.SonaroidsApp`: `getVolume()`, `setVolume(f)`, `route()` (динамик / проводные / Bluetooth), `info()` (версия, модель, SDK, есть ли «сырой» микрофон), `checkUpdate()`.

## Обновления

- **Игра** обновляется сама: страница берётся с сайта, её service worker сначала идёт в сеть — новая версия приходит при следующем запуске. После паузы дольше 30 минут на главном экране приложение само перезагружает страницу. На главном экране в приложении есть «Проверить обновление» — он же перезагружает страницу.
- **Само приложение** (эта папка) меняется редко. Сборка — `.github/workflows/android.yml` на GitHub: после каждой распаковки архива (и когда запущена вручную), если `android/` поменялась, собирает APK и выкладывает релиз `android-N` с файлами `sonaroids.apk` и `app.json`. Приложение при каждом запуске (и по «Проверить обновление») читает `app.json` последнего релиза и, если сборка новее, предлагает скачать APK.
- Ссылка на последнюю сборку: `https://github.com/neokrasav4ik/sonaroids/releases/latest/download/sonaroids.apk`.

## Один раз руками

1. **Файл сборки.** Распаковка архива не трогает `.github/` — файл `.github/workflows/android.yml` из архива надо один раз добавить в репозиторий руками (GitHub → Add file → Create new file, путь `.github/workflows/android.yml`, вставить содержимое).
2. **Ключ подписи** (чтобы новые сборки ставились поверх старых). На любой машине с Java (например, на сервере: `sudo apt install openjdk-17-jre-headless`):
   ```
   keytool -genkeypair -v -keystore sonaroids.jks -alias sonaroids -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Sonaroids"
   base64 -w0 sonaroids.jks > sonaroids.jks.b64
   ```
   В GitHub: Settings → Secrets and variables → Actions → New repository secret: `ANDROID_KEYSTORE_B64` — содержимое `sonaroids.jks.b64`, `ANDROID_KEYSTORE_PASS` — пароль, который спросил keytool. Файл `sonaroids.jks` сохранить в надёжном месте: без него обновления для уже установленных приложений не подписать. Без секретов сборка подписывается одноразовым ключом — перед установкой новой сборки старое приложение надо удалить.
3. **Установка на телефон:** открыть ссылку на последнюю сборку в браузере телефона, скачать, разрешить установку из этого источника.

## Устройство

`app/src/main/java/app/sonaroids/MainActivity.java` — всё приложение: WebView, разрешение микрофона (`onPermissionRequest` — только для sonaroids.app), мост `SonaroidsApp`, проверка обновлений, перезагрузка после паузы. Ссылки не на sonaroids.app открываются в браузере телефона. Номер сборки (`versionCode`) — номер запуска на GitHub, имя — `VERSION.N`. Здесь (в песочнице Claude) Android SDK недоступен — код проверяется javac на заглушках, собирается на GitHub.


## Свой звук приложения (v0.50)

`NativeAudio.java`: приложение само пишет микрофон (AudioRecord, 48 кГц, наименее обработанный источник) и играет зонд (AudioTrack), а страница только обрабатывает. Кадры идут в страницу через WebMessagePort. Включается на служебном экране: главный экран → тап по версии → «ЗВУК» → «ПРИЛОЖЕНИЕ». Там же выбираются микрофон (с тем, где он стоит, если телефон это сообщает) и динамик; внизу — что реально работает сейчас. По умолчанию звук идёт через браузер, как раньше.
