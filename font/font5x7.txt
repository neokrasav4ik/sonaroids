# Sonaroids pixel font, 5x7. Source for font/make_font.py, which writes game/font.js.
# Each glyph: a line "== X" (the character), then its rows of . and #, up to 5 columns wide.
#   7 rows  = rows 0..6, capital height; lowercase letters leave rows 0..1 empty (x-height is 5).
#   8-9 rows = plus descender rows below the baseline.
#   "== X ^" = the first row is an accent row above the capitals (Ё, Й).
#   "== X = Y" = X looks exactly like Y (Cyrillic А = Latin A, and so on).
# Empty columns on the left and right are trimmed, so the font is proportional; letters are 1 pixel apart.
