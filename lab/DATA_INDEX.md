# Sonaroids — данные: записи и журналы

Все записи и журналы, присланные до 25.09.2026 (55 файлов, ~480 МБ), разложены по четырём архивам; каждый архив разбит на части до 30 МБ (`…_part1of6.zip` и т. д. — так их можно отдать через чат), итого 16 zip-файлов. Файл лежит целиком в одной части. Архивы хранит автор; в проект и в репозиторий аудио не кладётся. Для разбора нужный архив прикладывают к чату и гоняют инструментами из `lab/tools/` (всё сразу — `sh lab/tools/run_data.sh папка`).

Имена с приписками `_oneplus`, `_redmi`, `_redmi_cam`, `_android`, `_4-12` дописаны при разборе; на телефоне у файлов их нет.

Старый зонд — полоса 17,75–20,5 кГц, 29 частот, до утра 24.09. Новый — 18,3–20,44 кГц, 23 частоты, с автоуровнем, в метаданных есть `f_lo`. Инструменты различают их сами.

**Виды файлов.** `sonarark_*` (с 27.09) — прототип Арканоида из лабы (`eval_ark.js`). `sonar1r_*` и `sonarright_*` (с 27.09) — «Ладонь справа»: запись по метке (`eval_recording.js`) и проба-игра (`eval_right.js`). `sonardual_*` (с 27.09) — «Два динамика» из лабы: каналы по очереди и вместе, палец на верхнем динамике, ладонь вдоль длинного края (`eval_dual.js`). `sonarside_*` (с 26.09) — «Запись вбок» из лабы: телефон вертикально, ладонь ребром у разъёма ходит влево-вправо по метке (`eval_side.js`). `sonarlong_*` — длинная запись по метке (`eval_long.js`). `sonar1h_*` — «Запись для меня» из лабы: ладонь по сценарию с меткой, для проверки механики по линейке (`eval_recording.js`, `eval_variant.js`). `sonar_game_*` / `sonar_setup_*` — журналы партии и подготовки из лабы. `sonaroids_game_*` / `sonaroids_setup_*` — те же журналы из самой игры (кнопка «ЖУРНАЛ» после партии; с 0.27 она появляется после тапа по версии): звук микрофона PCM16 и кусок `glog` с JSON по кадрам обработки, кадрам игры и событиям; разбор — `game_log.py`, `setup_log.py`, `replay_game.js`. В партии пишутся последние 150 с; «счёт» ниже — на конец записи.
